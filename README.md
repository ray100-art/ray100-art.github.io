# Brian Ndung'u · Portfolio

Personal portfolio, live at **https://ray100-art.github.io/**.

It presents my work as engineering case studies (problem, design, trade-offs, result) for
ParkNairobi, DaktariAssist, DRIP Commerce and the School Record Management System, plus
my skills and how to reach me.

## Built with

- One hand-written `index.html`: semantic HTML5, modern CSS (grid, custom properties) and
  vanilla JavaScript, with no framework and no build step
- Instrument Sans and JetBrains Mono from Google Fonts
- Accessibility: skip link, visible focus states, labelled form fields, `prefers-reduced-motion` support
- SEO and sharing: meta description, Open Graph and Twitter card tags, a 1200×630 preview
  image (`og-image.png`), and schema.org `Person` data
- Contact form posted to Formspree with `fetch`, reporting the real result (sent, or failed
  with a fallback email link)
- Hosted on **GitHub Pages**; every push to `main` deploys

## Run locally

```bash
python -m http.server 8000
# open http://localhost:8000
```
