# Brian Ndung'u — Portfolio

Personal portfolio site, live at **https://ray100-art.github.io/**.

It covers who I am, the skills and technologies I work with, featured projects (ParkNairobi,
the DRIP e-commerce platform, an expert system in Prolog, and more), and how to get in touch.

## Built with

- A single hand-written `index.html`: semantic HTML5, CSS3 and vanilla JavaScript, with no
  framework and no build step
- Google Fonts (Playfair Display, Lato)
- Hosted on **GitHub Pages**, so every push to `main` deploys automatically

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
# open http://localhost:8000
```
